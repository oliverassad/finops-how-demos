# finops-how demos

Hands-on labs for the guides on [finops.how](https://finops.how). Each folder is one lab. Each lab runs on a laptop, needs no cloud account, and costs nothing.

| Lab | Guide | What you do |
| :-- | :-- | :-- |
| [container-cost-allocation](container-cost-allocation/) | FinOps for Containerized Environments: How to Allocate Their Costs | Run a local Kubernetes cluster with OpenCost and read the cost of four teams. |
